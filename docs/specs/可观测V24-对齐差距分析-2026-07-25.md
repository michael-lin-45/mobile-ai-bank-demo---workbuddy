# A. 混淆矩阵呈现方案调研

> 现状：本项目混淆矩阵 = 5×5（5 类意图：实际 vs 预测），当前 DEMO 与前端 `HeatmapChart` 均为「**按行归一化热力图 + 单元格 count%+pct% 双标注 + 对角线 + ≥5% 暖色描边 + caption**」。**主人均反馈"很乱，含 V24"**。

## A.1 当前"乱"的根因

| # | 根因 | 说明 |
|---|------|------|
| 1 | **未归一化 / 归一化口径不清** | 用户常误以为颜色=绝对计数，但本图是按行归一化（占"实际意图"比例）。轴标签未写明"行=%"，极易与列归一、原始计数混淆。 |
| 2 | **缺轴标签语义 / 单位** | 仅写"预测 / 实际"，未说明"单元格数值是占该实际意图的百分比"，无单位提示。 |
| 3 | **颜色梯度不区分主次** | 单色蓝渐变（#f5f5f5→#1677ff），对角线 88–98% 深蓝、非对角浅蓝，**错误格与低值正确格同色系**，肉眼难抓"哪里混淆最严重"。 |
| 4 | **单元格数字拥挤** | 5×5=25 格，每格塞 `count\npct%` 两行数字 → 50 个数字，大屏缩略/移动端下可读性崩。 |
| 5 | **对角线未突出** | 对角线（正确分类）与错误格仅差深浅，无强对比（如绿/灰底），第一眼看不到"主干是否厚实"。 |
| 6 | **类目增多即崩** | 5 类尚可，若扩到 8–10 类意图，热力图变成棋盘，信息密度超过人眼解析上限。 |
| 7 | **暖色描边阈值生硬** | ≥5% 才描边，3–4% 的"准混淆"完全隐形；描边仅 2 档（橙/红），不分严重度梯度。 |

## A.2 业界优秀呈现方案（5 种）

### 方案 1 — 按行归一化热力图 + 对角线加深高亮 + 单元格只标百分比
- **适用场景**：类目 ≤ 8、需保留完整结构、作为大屏常驻组件。
- **做法**：对角线用强对比色（深绿/深灰）铺底；非对角仅显示**百分比**（count 移入 tooltip）；轴标签显式写"实际意图(行) / 预测意图(列)"并标注"单元格=占该行比例"。
- **优点**：结构全、一屏看尽；百分比跨类目可比；对角线一眼可辨。
- **缺点**：仍是热力图，密集类目下仍偏挤；需靠配色纪律保证"错误可见"。
- **代表实现/库**：`seaborn.heatmap(annot=True, cmap=..., mask=diag)`、`plotly.express.imshow`、`echarts heatmap` + `visualMap` 分段。

### 方案 2 — 分组/堆叠横向条形图（Per-Class 错误分解）
- **适用场景**：更关心"每个真实意图被错分到了哪"，而非全局对称结构。
- **做法**：每行（实际意图）一条横向堆叠条，对角线段用绿色、各错误预测段用暖色梯度，图例按预测类目着色。
- **优点**：**错误被显式放大**，颜色语义清晰（绿=对、暖=错）；条形长度天然可比；移动端可纵向滚动。
- **缺点**：失去矩阵"交叉定位"直觉；类目多时图很长。
- **代表实现/库**：`matplotlib barh(stacked)`、`plotly bar(stack)`、`vega-lite` stacked bar。

### 方案 3 — 错误聚焦视图（Top-N 混淆对 + 可选 Sankey 流图）
- **适用场景**：大屏/汇报只看"最该修的混淆"，或作为热力图的**辅助**而非替代。
- **做法**：隐藏对角线，仅列出非对角混淆对按占比排序（如 "理财咨询→理财解读 13.6% / 理财解读→理财咨询 13.4%"）；可加 `实际→预测` 的 Sankey 流图呈现误分流向。
- **优点**：信息密度最低、结论最直给；Sankey 直观展示"流到了哪"。
- **缺点**：丢失"哪些类目完全没问题"的全貌；需配合主视图。
- **代表实现/库**：`plotly Sankey`、`echarts Sankey`、`d3`、简单 `antd Table` 排序列表。

### 方案 4 — 单一标量关联强度摘要（Cramér's V / Cohen's κ）+ 紧凑矩阵
- **适用场景**：大屏需要"一眼定级"，或在矩阵右上角给一个总结标量。
- **做法**：在矩阵旁放一个摘要卡：整体准确率、Macro-F1、**Cramér's V**（0–1，越大越混淆）或 Cohen's κ；用 V 值决定健康灯（绿/黄/红）。
- **优点**：把"乱不乱"压成一个数，便于跨时段/跨版本对比与告警；非技术干系人友好。
- **缺点**：标量掩盖细节，必须配矩阵或 Top-N 使用。
- **代表实现/库**：`sklearn.metrics.confusion_matrix`、`cohen_kappa_score`、自定义 Cramér's V（`sqrt(χ²/(n·(k-1)))`）。

### 方案 5 — 发散（Diverging）配色归一化热力图
- **适用场景**：强调"偏离正确分类的程度"，弱化绝对量级。
- **做法**：用 0 居中的发散色板（白=基准，红=误差越高越深），对角线中性的同时让错误格"越红越严重"，分多档（≥5% 橙、≥10% 红、≥15% 深红）。
- **优点**：错误严重度有连续梯度，比当前"2 档描边"细腻；颜色即语义。
- **缺点**：仍需处理数字拥挤与轴标签。
- **代表实现/库**：`matplotlib DivergingNorm` + `RdBu_r`、`seaborn.diverging_palette`、`echarts visualMap` 分段 inRange。

## A.3 针对本项目的推荐方案（明确结论）

**推荐组合（主 + 辅）：**

> **主视图**：方案 1（按行归一化热力图）+ 对角线**深绿铺底**高亮 + 单元格**只显示百分比**（count 移入 tooltip）+ 轴标签显式写「实际意图(行) / 预测意图(列)」并标注"单元格=占该行实际意图比例" + 右上角挂**方案 4 的 Cramér's V 摘要卡**（如 V=0.12，健康灯）。
>
> **辅视图**：在矩阵下方加一行**方案 3 的 Top-3 混淆对**（如 "⚠ 理财咨询↔理财解读 13.6%/13.4%"），作为大屏结论钩子。
>
> **配色升级**：对角线绿、非对角用方案 5 的发散色板（白→橙→红三档以上，替换当前单色蓝），让"混淆越重越红"。

**理由（结合本项目 5×5 + 大屏/AI洞察双场景）：**
1. **保留结构 vs 大屏常驻**：5 类意图用热力图最紧凑，比堆叠条形/ Sankey 更适合大屏长期驻留；同时用"对角线绿 + 百分比 + 发散红"三条纪律解决根因 3/4/5/7（颜色不区分、数字挤、对角线不突出、描边生硬）。
2. **可读性**：单元格只标百分比、count 进 tooltip → 直接消除"50 数字拥挤"（根因 4）；轴标签写清口径 → 消除"归一化误解"（根因 1/2）。
3. **大屏定级**：Cramér's V 摘要卡让值守人员一眼判断"本次混淆是否恶化"，契合金融运维"先定级后下钻"。
4. **移动端/窄屏降级**：5×5 在窄屏仍可读；若屏幕更窄（手机），自动降级为**方案 3 的 Top-N 混淆对条形列表**（隐藏完整矩阵），保证核心结论不丢。
5. **AI洞察页**：保持与准确率分析 TAB 同一张热力图（已在 `AccuracyTab`/`HeatmapChart` 落地），仅做上述美化，无需新增数据结构。

**不建议**：全量换成纯条形图/Sankey（丢失对称结构、大屏占位变大）；也不建议保留当前"蓝渐变 + 双数字 + 2 档描边"原样。
